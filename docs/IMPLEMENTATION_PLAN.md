# 차량 전면부 실시간 인식 구성안
작성: 2026-10-28 / Origin1332/Mobility-Inspecter

## 목표와 범위
Android 태블릿 후면 카메라에서 YOLO로 차량 전면부 부품을 탐지하고 바운딩 박스, 한국어 부품명, 신뢰도 및 점검 참고 정보를 표시한다. 영상은 외부 전송하지 않는다. 부품 탐지는 손상/고장 판정이 아니다.

## 데이터와 모델
로컬 Downloads/dataset_front_reviewed.zip의 수정된 좌표와 원본 10개 클래스 순서를 보존한다. 픽셀 xyxy를 정규화 YOLO xywh로 변환하고 이미지 크기, 좌표, 중복, 클래스 분포를 검증한다. 고정 시드로 train/val을 분리한다. 좌우 라벨을 위해 수평 뒤집기 증강을 끈다. 작은 표본과 미학습 클래스는 보고서에 명시한다.
YOLOv8n → ONNX FP32 입력 [1,3,640,640], 출력 [1,4+C,8400], 외부 클래스별 NMS를 사용한다. 모델 SHA-256, 클래스 목록, 입력 크기를 manifest에 저장한다.

## 앱 구조
Kotlin + CameraX + ONNX Runtime Android, Android 8(API 26) 이상. RGBA 프레임 회전 보정 → letterbox → RGB CHW 정규화 → 추론 → NMS → 원본 좌표 복원.
분석한 프레임 자체에 결과를 그려 화면과 좌표를 일치시킨다. 최신 프레임 우선 처리, 단일 추론 스레드, 카메라 생명주기 연동을 적용한다.
모델 ZIP 가져오기, 카메라 권한 안내, 신뢰도 조정, 일시정지, 부품 선택과 설명을 구현한다.

## 순서와 검증
1. 데이터 변환/검증, 학습/모델 패키징 도구.
2. Android 실시간 화면과 추론 엔진.
3. 데이터 단위 테스트, 좌표/NMS 테스트, 가능한 빌드와 학습.
4. FINAL_REVIEW.md에 스택/구조/실행 결과/미검증 사항을 기록한다.
APK 생성과 태블릿 검증이 없으면 실기기 실행 완료로 표현하지 않는다. 가로/세로, 권한 거절/재허용, 백그라운드 복귀, 10분 발열/속도와 실제 탐지 정확도를 검증한다.
